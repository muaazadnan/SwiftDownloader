# Changelog

## [1.0.0] - 2024-01-01

### Added
- Initial release of SwiftDownloader
- Multi-connection accelerated HTTP/HTTPS downloads
- Pause, resume, and auto-retry support
- Download queue management
- Download scheduler (once, daily, weekly)
- Professional PySide6 interface with dark and light themes
- Dashboard with real-time statistics
- Automatic file categorization
- SHA-256 file hash verification
- Browser extensions for Chrome, Edge, and Firefox
- Native messaging host for browser integration
- Clipboard URL monitoring
- Download history with search
- System tray support with minimize-to-tray
- Speed limiter
- Configurable connection limits
- Database backup
- Import/export download lists
- Comprehensive settings panel
- Automatic Windows architecture detection
- Windows installer (Inno Setup)
- Portable executable version
